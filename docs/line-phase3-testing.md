# 第三階段本機測試

更新：2026-10-04。仍是虛構資料預覽，未部署、未發真實 LINE 訊息。

## 報名與選場

1. 開啟 `http://127.0.0.1:8769/?registration&as=leader`，選自己的球團與活動。
2. 完成第二階段的綁定／群組登錄，連結活動至群並模擬發布公告。若既有第二階段測試活動顯示「更新本場群組連結」，按一次以建立新版活動內的授權關聯。
3. 在本機 LINE 模擬器，把「模擬發話者」切為「一般球友甲（不綁定）」。輸入「測試小明+2」，按模擬群內訊息。
4. 只有一場有效活動時直接處理；多場時出現選場按鈕及完整球團／日期清單。點一場才報名，不按最新活動猜測。
5. 查看回覆與後台：應有測試小明1、測試小明2；再次送相同姓名會警告，不新增名額。
6. 測試「測試小明1-1」、「固定甲-1」、「取消請假 固定甲」、「查名單」及單獨「+1」。單獨 +1 提示加姓名；固定請假／恢復按姓名，不需 LINE 綁定，額滿不得恢復。
7. 多場選擇時可切換發話者為一般球友乙再點甲的按鈕，應拒絕。選擇只限原群、原發話者、5 分鐘內、單次使用。選場後活動暫停、過期或停止群連結，不能執行舊選擇。

LINE／網頁寫入相同活動資料，以交易保護名額。LINE 成功操作在活動內記錄訊息識別，重送不再新增；網路回覆失敗時應查名單確認，不猜測成功。群內查名單沒有手機、付款資訊或私有識別。取消與查名單可處理尚未結束但暫停報名的本場，新增／恢復須開放。

選場使用 LINE quick reply／postback，每次最多列前 13 場；其餘可用本場網頁連結。依據：[LINE quick reply 文件](https://developers.line.biz/en/docs/messaging-api/using-quick-reply/)。桌面端／無法辨識操作者的多場流程也請用本場網頁連結。

## 自動停止與每週單場

- 活動结束時間以台灣時區計算，到結束瞬間即拒絕 LINE／網頁報名，不依賴每天排程是否執行。
- 排程會將已過期活動的 registrationOpen 關閉；前場名單與人工排點不刪除。團長仍可事後整理歷史名單、匯入與結算。
- 同一週期系列只允許一場有效報名，前場結束且到提前開放日後才輪到下一場。既有測試資料曾提前生成下一週，也不允許兩週同時報名；後台顯示等待前場結束／開放日。
- 建立過去日期的單次活動，可以立即看見已結束、不能開放報名。結束時間到達時管理畫面會重新查詢；公開報名 API 每次操作均重新檢查。
- 後台的「本機排程測試」可用未來時間確認每週續開及重跑不重複，但不會改變整台機器的時間。它能將虛構舊場關閉，不能用來模擬所有 API 的時鐘；精確截止瞬間由自動測試驗證。
- 新週活動仍需團長連結可用群組並輸入本場發布指令；不自動公告、匯入或入帳。

## 實作與驗證範圍

新增 activity-time 統一截止與同系列判斷、line-registration 群訊息與 postback 路由。活動中的 linePublications 是群組關聯的授權檢查，與名單同在球團 transaction；lineCommands 保存已完成訊息去重。lineIntegrationV2 的 choices／choiceRequests 保存短效選場與請求去重，公開 API 不回傳。

目前 58 項自動測試通過，涵蓋姓名代報、重複報名、最後名額競爭、請假與額滿恢復、跨人／跨群／過期選場、截止瞬間及同週期場次限制；另有本機介面測試。正式 RTDB 並行、真實 LINE 網路／群組回呼、部署與新私有路徑規則仍待正式測試授權；此版本不宣稱已完成正式上線驗證。
